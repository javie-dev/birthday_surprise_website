# Lang's Birthday Website 💗

## Run locally
1. Extract this folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in your browser. Recommended: install the VS Code extension **Live Server**, then right-click `index.html` → **Open with Live Server**.

## Add your photos
Copy three pictures into the `images` folder and name them exactly:
- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`

If your images are PNG, either convert them to JPG or update the filenames in `index.html`.

## Add a song (optional)
Put an MP3 file in the `music` folder and name it `our-song.mp3`. Use a song you have permission to share. The browser only starts audio after the visitor clicks the play button.

## Customize the letter
Open `index.html` in VS Code and edit the paragraphs inside `<article class="letter-card">`.

## Publish free with GitHub Pages
1. Sign in at https://github.com and create a **new public repository**, for example `lang-birthday`.
2. Upload `index.html`, `style.css`, `script.js`, plus the `images` and `music` folders (keep the folder structure).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click **Save**.
6. Wait a minute or two. The Pages section will show the website URL, usually `https://YOUR-USERNAME.github.io/lang-birthday/`.

Keep in mind: a public GitHub Pages website is visible to anyone with the link and may be discoverable. If your photos are private, use pictures you are comfortable sharing publicly or skip the photo gallery.
